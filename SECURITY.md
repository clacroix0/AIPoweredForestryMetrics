# Security policy

## Public repository boundary

This repository is documentation-only. It must never contain production exports, live configuration, operational records, source PDFs, extracted document text, credentials, access tokens, signed links, or internal identifiers.

## Reporting a concern

Do not place sensitive details in a public issue. Use GitHub private vulnerability reporting when it is enabled for the repository, or contact the repository owner through an approved private channel.

A safe report may include:

- The affected public file
- A general description of the issue
- Steps that use only synthetic information
- The expected public-safe behavior

Do not attach real documents or screenshots from operational systems.
