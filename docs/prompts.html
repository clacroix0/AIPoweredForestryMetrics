Evidence first, consolidation second

The active design uses ten custom-prompt calls: five metric-specific evidence prompts and five final consolidation prompts.

First pass

Find evidence

Each long report is divided into overlapping chunks. A narrow prompt checks one metric and returns either a structured evidence record or an exact no-evidence token.

Second pass

Consolidate

Qualifying evidence records for one metric are reviewed together. The final prompt returns consistent labels, units, and short references for human validation.

Public-safe adaptation: these examples preserve the original design pattern but omit production wording, internal identifiers, policy configuration, and model records.

Shared guardrails

No inference

Only values explicitly present in the supplied text may be returned.

Metric separation

AAC, IAC, and RAC are treated as distinct measures and cannot be substituted.

Traceable output

Evidence includes an exact excerpt and a page or section hint.

Human review

Every output is a candidate finding that must be checked against the source.

Prompt pair

FMP plan period

Evidence prompt — first pass
ROLE
Locate plan-period evidence in one Forest Management Plan text chunk.

INPUT
{{chunk_text}}

RULES
- Use only the chunk text. Do not infer dates.
- Accept the plan year only when tied to approval/adoption language.
- Report start and end years only when explicitly stated.
- Return an exact no-evidence token when nothing qualifies.

RETURN
NO PLAN PERIOD EVIDENCE

or the labeled year fields plus an exact excerpt, page, and section.
Consolidation prompt — second pass
ROLE
Create one plan-period result from {{evidence_lines}}.

RULES
- Use only explicit dates.
- Prefer approval-page evidence for the plan year.
- Do not infer a date range.
- Surface conflicts.

RETURN

Plan Start Year: ...
Plan End Year: ...
Non-expiring: ...
References: ...

Prompt pair

FMP Allowable Annual Cut (AAC)

Evidence prompt — first pass
ROLE
Locate AAC evidence in one FMP text chunk.

RULES
- Require an AAC label or approved synonym near the number.
- Never report IAC or RAC as AAC.
- Preserve units and reject incompatible combinations.
- Include a short exact excerpt and location hint.

RETURN
NO AAC EVIDENCE

or AAC, timberland/woodland fields, units, excerpt, page, and section.
Consolidation prompt — second pass
ROLE
Create one AAC result from {{evidence_lines}}.

RULES
- Report only explicit AAC values.
- Keep timberland and woodland separate.
- Do not manufacture a total from incomplete evidence.

RETURN
AAC: ...
Timberland AAC: ...
Woodland AAC: ...
AAC Unit: ...
References: ...

Prompt pair

FIA commercial volume

Evidence prompt — first pass
ROLE
Locate commercial-volume and acreage evidence in one FIA text chunk.

RULES
- Require a volume label or approved synonym.
- Reject growth, mortality, stocking, basal area, AAC, IAC, and RAC.
- Read only clearly labeled tables.
- Preserve values and units as written.

RETURN
NO COMMERCIAL VOLUME EVIDENCE

or labeled volume/acres fields plus excerpt and location.
Consolidation prompt — second pass
ROLE
Create one commercial-volume result from {{evidence_lines}}.

RULES
- Prefer an explicit total over a calculated total.
- Do not add components unless an approved rule is active.
- Keep timberland, woodland, and acreage fields separate.

RETURN
Total Volume: ...
Timberland Volume: ...
Woodland Volume: ...
Acreage fields: ...
References: ...
